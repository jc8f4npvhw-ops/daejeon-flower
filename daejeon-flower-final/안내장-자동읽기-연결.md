# 부고장·청첩장 무료 자동 읽기

## 현재 구성
- 캡처: Tesseract.js 7.0.0 한국어+영어 모델로 고객 브라우저 안에서 처리. 인식용 사진·글자를 외부 OCR/AI 서버로 보내지 않으며 API 키나 건당 인식료가 필요하지 않습니다.
- 링크: 기존 Workers의 /api/notices/read가 삼가·바른손 letterb 페이지를 직접 읽음. 유료 AI 호출 및 자동 유료 대체 경로는 삭제했습니다.
- OCR 실행 파일/언어 데이터도 public/ocr에 포함해 같은 홈페이지에서 제공합니다. npm install 후 postinstall 또는 npm run ocr:prepare로 재생성. 고객에게 별도 앱 설치 불필요. 첫 실행에는 인식 파일 다운로드/준비 시간이 걸립니다. 인식 엔진 Apache-2.0 등 고지는 public/ocr에 보관.
- 이미지 8MB 이하 JPG/PNG/WEBP, 인식 최대 대기 120초, 입력 변경 시 취소/오래된 결과 무시. 휴대폰 성능/사진 품질에 따라 지연·오인식 가능.
- 글자만 읽고 항목으로 분리하지 못한 경우도 확인창에서 원문 글자를 보고 직접 입력할 수 있습니다. 누락된 연도·오전/오후·성함을 추측하지 않습니다.
- 인식 결과를 원본과 대조하고 '확인한 정보 입력하기'로 적용. 빈칸은 기존 입력을 지우지 않음. 발인과 예식/배송 일정은 분리.

## 운영 설정과 저장
- 기존 Workers/D1 DB/MEDIA R2 binding 유지. DB나 버킷 재생성/스키마 교체 없음.
- wrangler.jsonc에 NOTICE_READER_ENABLED=true, NOTICE_ALLOWED_HOSTS=samga.co.kr,letterb.barunsoncard.com 설정. 실제 링크 읽기는 서버 배포 및 기존 SESSION_SECRET 설정 후 사용. API 키는 불필요.
- 링크 요청의 출처/HTTPS/정확한 호스트/리다이렉트 재검증, 30초·500KB 제한, IP별 15분 최대10회 제한 유지.
- 새 링크 사이트는 확인한 전용 파서를 추가해야 합니다. 호스트 목록에 이름만 추가해도 자동으로 지원되지는 않습니다. 미지원/변경된 형식은 캡처 또는 수동 입력 안내.
- 브라우저 OCR은 HTTPS 또는 localhost로 서비스한 홈페이지에서 사용. 단독 file:// HTML은 인식 파일 경로가 없으므로 수동 입력 안내. 링크는 서버가 필요.
- 자동 읽기는 주문/미디어를 생성하지 않습니다. 캡처를 주문에 첨부할 경우 기존 주문 준비 흐름에서 비공개 R2에 저장합니다. '인식을 위해 전송하지 않음'과 주문 첨부 저장은 구분합니다.
- 최종 확인 정보는 기존 customization.noticeDetails에 저장되어 관리자 상세/인쇄에서 확인. 원본 인식 글자 전체는 주문 정보로 저장하지 않습니다.
- 주문/고객/사진 메타데이터는 기존 D1 DB, 사진 파일은 기존 R2, 홈페이지 실행은 Workers, 인식 실행파일은 정적 자산입니다. D1은 호스팅/파일 저장의 대체품이 아닙니다. OCR 건당료는 없으나 Cloudflare의 요금제·사용량 한도는 별도입니다.

## 지원 사이트
- samga.co.kr/obituary/indv/숫자: 장례식장/빈소/고인/상주/발인/주소. 계좌나 개인 연락처를 추출하지 않음.
- letterb.barunsoncard.com/inv-슬러그: 장소/홀/주소/신랑/신부/화면 표시 날짜와 시간. 타임스탬프의 시간을 예식 시각으로 환산하지 않음.
- 지난 일정은 확인창 경고. 실제 전달받은 페이지에서 직접 파싱을 확인했으나 사이트 형식 변경 시 추가 점검 필요.

## 검증과 한계
- 자동 테스트: 개인정보 없는 가상 안내장으로 필드 분리, 확인 후 적용, 빈칸 보존, 이전 요청 무시, 링크 호스트/속도 제한, 유료 호출 부재 검증.
- 한국어 가상 부고장/청첩장 PNG를 생성해 실제 Tesseract 엔진으로 장소·날짜·시간 인식을 검증했습니다. 브라우저 UI 연결은 모의 인식 응답으로 검증했으며 실물 캡처/휴대폰 정확도를 보장하지 않습니다.
- 실제 배포/고객 기기별 성능 및 복잡한 실물 안내장 정확도 검증은 별도입니다. 자동 읽기는 보조 기능이며 수동 입력을 항상 제공합니다.
- 공식 참고: https://github.com/naptha/tesseract.js 와 docs/local-installation.md.

## 빌드 확인
- 전체 자동 테스트 38건 및 TypeScript 검사 통과. Vite/vinext 실제 운영 빌드 성공.
- vinext check는 정적 public/ocr/core의 제3자 WASM 로더에 있는 Node 전용 분기의 CommonJS 전역 문자열을 문제로 표시합니다. 이 파일은 앱 코드로 import하지 않고 브라우저 Web Worker의 정적 자산으로 사용하며 실제 빌드는 성공했습니다. 정적 검사 메시지를 없애려고 제3자 엔진을 임의 수정하지 않습니다.
- 이 작업에서 원격 배포·D1 migration·R2 업로드·유료 API 호출은 하지 않았습니다.
