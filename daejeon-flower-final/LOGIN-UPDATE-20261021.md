# 관리자 로그인 저장 옵션 — 2026-10-21

- 로그인 상태 유지: 체크 시 로그인한 시점부터 30일, 미체크 시 기존 8시간. 로그아웃 시 해당 서버 세션이 폐기됩니다. 기존 세션은 재로그인해야 새 유지 기간을 적용받습니다.
- 아이디 저장: 로그인 성공 후 이 브라우저에 아이디만 저장. 체크 해제 즉시 이 사이트가 저장한 아이디를 삭제합니다.
- 비밀번호 저장: 로그인 성공 후 지원 브라우저의 비밀번호 관리자에 저장을 요청합니다. 브라우저의 확인·정책에 따라 저장 여부가 결정됩니다. 미지원 브라우저는 일반 비밀번호 저장/자동완성을 사용합니다. 홈페이지의 localStorage, 쿠키, D1에는 비밀번호 원문을 저장하지 않습니다. 기존 브라우저 저장 비밀번호의 삭제는 브라우저 설정에서 합니다.
- 체크박스는 세 항목 모두 24px로 통일하고, 제목·입력·버튼을 읽기 쉬운 크기로 조정했습니다.
- 기존 DB 스키마 및 SESSION_SECRET 변경은 필요하지 않습니다. 기존 DB/R2와 이미 등록한 비밀키는 유지합니다.
- Windows용 미디어 이전·초기 관리자 등록·세션키 생성 스크립트 호환 수정도 포함합니다. 이미 초기 설정이 끝났다면 이 스크립트들을 다시 실행하지 마세요.

## 적용

1. GitHub Desktop에서 daejeon-flower 저장소, cloudflare-latest 브랜치를 선택하고 Fetch origin / Pull origin으로 웹에서 수정한 README까지 받습니다.
2. 패치 ZIP을 압축 해제합니다. 안의 daejeon-flower-final 폴더를 GitHub 저장소 최상위 폴더에 복사하고, 동일 파일은 덮어씁니다. 폴더 자체를 삭제하거나 새 중첩 폴더를 만들지 않습니다.
3. GitHub Desktop 변경 목록에서 이 패치의 파일만 확인하고 커밋한 뒤 Push origin 합니다. 기존 Cloudflare Git 자동 빌드가 실행됩니다.
4. 배포 성공 후 관리자페이지를 새로고침합니다. 현재 로그인 중이면 로그아웃하여 세 체크박스를 확인하고, 로그인 상태 유지를 체크해 다시 로그인합니다.

## 검증

- TypeScript 검사 통과
- 로그인 관련 UI·서버 및 기존 서버 흐름 5개 테스트 통과
- 프로덕션 빌드 통과
- 30일/8시간 DB 만료와 쿠키 Max-Age 일치, 로그아웃·만료 차단, 실패 로그인 시 저장 요청 없음, 아이디만 로컬 저장, 아이디 저장 해제 시 삭제 확인
- 실제 사용자 Cloudflare 계정의 새 버전 배포 및 실제 브라우저 비밀번호 관리자 확인은 적용 후 수행해야 합니다.
