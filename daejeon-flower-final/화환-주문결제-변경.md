# 화환 대표사진·주문 결제 변경 · 2026-10-18

근조: 제공한 근조 3단 현장사진을 기준으로 장례식장 출입구와 타일바닥이 함께 보이는 대표사진으로 편집.
축하: 제공한 축하화환 사진을 기준으로 예식장 출입구와 로비가 보이는 대표사진으로 편집.
두 사진 왼쪽 리본: 대전꽃백화점. 원본 화환 구성과 색상 최대한 보존. 식별 가능한 고인·보내는 분 정보 제거.
이미지 제작: 내장 imagegen 사용. 프로젝트 경로: public/media/category-funeral-venue.png, category-celebrate-venue.png.
주요 제작 지시: 원본 화환 보존, 전체 화환과 실제 한국 장례식장/예식장 출입구·바닥 표현, 자연스러운 조명과 접지 그림자, 왼쪽 대전꽃백화점 세로 붓글씨, 개인 식별 정보 없음.

## 주문 흐름
상품 > 장소 > 주문자 > 리본 > 최종 확인 > 주문·결제 > 결제 수단 선택.
복사/카카오톡으로 전송 제거. 최종 단계 전화 문의 1개.
부고장·청첩장 링크/캡처는 참고자료로 함께 접수. 장소·호실·성함·수령 담당 연락처 필수.
예식 날짜/시간 필수. 근조 배송시각 임의 생성 금지: fulfillment_at=NULL, 접수 후 매장 확인.
캡처는 결제 요청 시 비공개 R2, D1에는 경로 메타데이터만. 관리자 주문 상세에서 링크/캡처 확인. 배송완료 사진과 구분.
서버 상품가격/배송비 재계산, 결제요청 중복 방지. 결제 승인 후 NEW 주문.

## 실운영 전 입력
관리자 운영 설정의 화환 배송비(0원 포함)를 확정해야 함. 미입력은 임의 무료배송 처리하지 않고 결제 차단.
PG 공개/비밀키와 PAYMENTS_ENABLED, 관리자 실결제 설정, 운영 약관·개인정보·환불 안내 필요.
현재 원격 D1 변경/배포/실결제 수행 없음. 기존 D1, R2 바인딩 유지. 스키마 추가 변경 없음.
고객 UI 미리보기에서는 주문·결제 화면 진입 가능, 실제 주문/결제 불가 표시.
