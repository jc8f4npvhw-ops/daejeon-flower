대전꽃백화점 — 카카오 로그인·회원가입 / 추가 기능 신청 준비본

이 파일이 카카오 연결 작업의 최신 안내입니다.
아직 운영 사이트에 배포하거나 카카오 추가 권한 신청을 제출하지 않았습니다.

구현한 실제 페이지
 /register : 카카오 시작 → 인증 성공 후 선택형 가입 정보 입력
 /account  : 내 정보, 내 주문, 기념일·쿠폰, 톡캘린더·친구 메시지
 /terms    : 관리자가 저장한 서비스 이용약관
 /privacy  : 기존 개인정보처리방침. 회원 필수 생년월일 문구를 선택형 월·일 안내로 조정
 /api/auth/kakao/callback : 서버 전용 카카오 콜백

가입 정보
 - 카카오 회원 식별번호와 약관 동의 이력으로 회원을 식별합니다.
 - 이름·전화번호·양력 생일(월·일)은 선택입니다. 출생 연도는 수집하지 않습니다.
 - 카카오 수집 권한이 아직 없어도 인증 후 직접 입력하는 가입 화면이 동작합니다.
 - 권한 승인 뒤 KAKAO_LOGIN_SCOPES에 name,phone_number,birthday를 설정하면 카카오 동의 정보가 자동 입력됩니다.
 - 미동의 항목은 빈칸으로 남습니다. 고객은 비워둔 채 가입할 수 있습니다.
 - 가입만으로 광고 수신, 기념일 저장, 캘린더 쓰기, 친구 메시지 전송을 실행하지 않습니다.
 - 카카오 채널 친구 추가는 카카오 로그인과 별개입니다.

기존 정보 보호
 - 입력한 전화번호만으로 다른 비회원 주문·기념일 계정과 합치지 않습니다.
 - 새 회원의 카카오 확인 전화번호가 기존 고객과 겹치면 기존 데이터에 접근하지 않습니다.
 - 이때 기념일 날짜 저장은 가능하나 발송 연락처 확인은 매장 본인 확인이 필요합니다.
 - 로그인 후 새로 주문한 내역만 내 주문에 연결합니다. 기존 비회원 주문은 자동 합치지 않습니다.
 - 관리자 역할·기존 배송사진 알림·결제 설정은 유지합니다.

소규모 수정 ZIP 적용
1. 압축은 다운로드 폴더에서 풀고, 안의 daejeon-flower-final 내용물을 저장소의 같은 폴더에 덮어씁니다.
2. 기존 GitHub 저장소/브랜치는 daejeon-flower / cloudflare-latest입니다.
3. 기존 daejeon-flower-final 안 retry-db-preparation.cmd를 실행합니다.
   0011_kakao_members.sql의 없는 테이블만 추가합니다. 과거 마이그레이션 전체를 다시 실행하지 마세요.
   READY를 확인하세요. STOP이면 Push하지 말고 오류를 공유해주세요.
4. 아직 로그인 연결 정보를 설정하지 않았다면 이 상태로 배포해도 로그인은 OFF입니다.
   키를 먼저 설정할 때는 아래 '키 연결'을 완료한 뒤 Commit/Push합니다.
5. GitHub Desktop에서 변경 파일 확인 → Commit → Push origin → Cloudflare 배포 성공 확인.

키 연결 — 비밀번호나 키를 채팅에 보내지 마세요
1. 카카오디벨로퍼스 앱 ID 1640874의 카카오 로그인 사용 설정을 ON으로 합니다.
2. 앱 → 플랫폼 키 → REST API 키 설정에 아래 리다이렉트 URI를 등록합니다.
   https://xn--js0bx4ezvk5jm1b610k.com/api/auth/kakao/callback
3. Client Secret은 활성 상태를 유지합니다. REST API 키와 Client Secret을 본인 PC에서 확인합니다.
4. 저장소 앱 폴더 안 configure-kakao.cmd를 실행합니다. Node.js/npm과 이전에 설치한 Wrangler가 필요합니다.
5. 카카오 콘솔 설정을 완료했다면 YES 입력 후 키 두 개를 숨김 입력으로 넣습니다.
   키는 소스 파일에 저장하지 않고 Cloudflare의 암호화된 Secret으로 전송합니다.
   PUBLIC_ORIGIN은 위 대표 도메인으로 설정합니다.
6. 이 스크립트는 로컬 wrangler.jsonc에 KAKAO_LOGIN_ENABLED=true를 반영합니다.
   KAKAO_LOGIN_TEST_ONLY=true를 유지하여 일반 고객이 시험 가입하지 못하게 합니다.
   자동 알림·쿠폰·실제 결제·친구 메시지·톡캘린더 운영 스위치는 켜지 않습니다.
7. DB 준비 READY → Commit/Push → Cloudflare 배포 성공 확인.

실제 회원가입 테스트와 개인정보 권한 신청
1. 대표 도메인 https://xn--js0bx4ezvk5jm1b610k.com/admin 에서 OWNER로 로그인합니다.
   workers.dev 주소에서 로그인한 관리자 쿠키는 대표 도메인과 공유되지 않습니다.
2. 같은 브라우저에서 대표 도메인의 /register를 엽니다.
3. 카카오로 시작하기 → 본인 카카오 인증 → 이름·전화번호·생일 선택 입력 화면을 확인합니다.
4. 필수 약관 동의 후 가입 → /account 기념일 저장 → 로그아웃 → 다시 카카오 로그인.
5. 저장한 기념일이 다시 보이는지 확인하고, 실제 가입 화면을 캡처합니다.
   개인정보가 들어간 화면은 반드시 가린 뒤 제출합니다.
6. 카카오 추가 기능 신청: 이름/전화번호/생일 선택 동의, 나머지 사용 안 함.
   회원가입 링크는 대표 도메인 /register, 처리방침 링크는 /privacy입니다.
   실제 동작 화면과 사실에 맞는 수집 목적을 첨부합니다.
7. 위탁 업체, 국외 처리 사실, 시행일 등 기존 개인정보처리방침의 확인 대기 내용을 확정해야 합니다.
   확인 대기 문구를 임의로 지워 심사 완료로 표시하지 않습니다.

톡캘린더
 - 선택한 내 기념일의 다음 날짜 한 번만 추가합니다. 오전 10시–10시30분(한국시간), 3일 전 알림입니다.
 - 매년 반복 일정이 아닙니다. 홈페이지의 알림톡·쿠폰과 별개입니다.
 - 기념일 이름과 날짜만 카카오로 보내며 개인 메모는 보내지 않습니다.
 - 실제 연결/등록은 API 사용 권한, 동의항목, 테스트가 준비된 후 KAKAO_CALENDAR_ENABLED=true에서 동작합니다.
 - 앱 멤버 테스트 → 실제 추가 화면 캡처 → 권한 신청 → 승인 후 일반 고객 공개 순서입니다.

친구 목록·메시지
 - 서비스에 연결하고 필요한 동의에 참여한 친구만 표시됩니다. 전체 주소록 기능이 아닙니다.
 - 표시된 친구를 고객이 직접 선택하고, 보낼 내용을 확인한 뒤 메시지를 보냅니다.
 - 고정 문구: 함께 꽃 선물을 골라볼까요? 대전꽃백화점에서 꽃과 식물을 살펴보세요.
 - 홈페이지 링크를 포함하며 기념일 메모·주문 정보는 보내지 않습니다.
 - 앱 멤버인 발신자/수신자 두 계정과 카카오 동의항목 friends,talk_message가 필요합니다.
 - KAKAO_FRIENDS_ENABLED=true에서만 제공됩니다. 실제 테스트 발송은 수신자와 내용을 확인한 후 진행합니다.
 - 매장이 고객에게 보내는 기념일 알림은 이 API로 대체하지 않고 기존 비즈메시지 경로를 유지합니다.

외부 전송 보호
 - 캘린더/메시지는 확인 버튼을 눌렀을 때만 전송합니다.
 - 시간 초과 등 결과가 모호하면 자동 재전송하지 않습니다.
 - 캘린더는 기념일/날짜 중복, 메시지는 동일 요청 ID의 중복 전송을 막습니다.
 - 기능별 액세스 토큰은 서버에서 암호화해 최대 1시간만 저장합니다. 브라우저/소스/로그에 토큰을 노출하지 않습니다.
 - OAuth 연결 계정이 기존 로그인 계정과 일치하고 필요한 동의가 있는지도 확인합니다.
 - 로그아웃 또는 기능 연결 정보 지우기 시 저장한 기능 토큰을 제거합니다.
 - 카카오 계정 자체의 동의 철회는 카카오 계정 설정에서 별도로 처리합니다.

카카오모먼트
 - 광고 관리용 별도 권한 신청입니다. 사용 정책 확인과 비즈니스 인증 준비가 필요합니다.
 - 이 배포로 광고를 만들거나 집행하거나 예산을 설정하지 않습니다.
 - 광고 계정/비즈니스 인증 요건 확인 및 약관 동의 단계는 별도 승인 후 진행합니다.

일반 고객 공개 전
 - 실제 카카오 가입/재로그인, 기념일 저장/수정, 주문 연결, 모바일 화면을 확인합니다.
 - 개인정보처리방침 사실관계와 보존·삭제 업무를 확정합니다.
 - 준비 후 KAKAO_LOGIN_TEST_ONLY=false로 변경해 Commit/Push합니다.
 - 추가 기능 운영 스위치는 각각 승인과 테스트가 끝난 뒤 켭니다.

검증: 자동 테스트 113개 통과, TypeScript 검사 통과, 프로덕션 빌드 통과. OAuth·캘린더·친구 메시지 API는 자동 테스트에서 모의 응답으로 검증했으며 실제 카카오 계정 연동 및 실발송은 아직 수행하지 않았습니다. 화면 상호작용은 DOM 기반 테스트로 검증했고 실제 브라우저·모바일 화면은 배포 후 점검합니다.
