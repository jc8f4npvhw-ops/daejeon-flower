# 동의 체크와 방문 안내 버튼 정돈 · 2026-10-19

- 주문 개인정보 동의와 이용약관·취소환불 동의 체크박스를 20×20px로 통일했다.
- 두 칸 레이아웃으로 체크박스와 문구를 나눠 긴 문구에도 체크박스가 줄거나 줄이 어긋나지 않게 했다.
- 화환 결제에도 같은 규격을 적용했다. 체크박스 의미와 필수 동의 조건은 유지했다.
- 약도 아래 길찾기와 전화하기는 2열의 같은 높이 버튼, 네이버 매장정보는 아래 전체 폭 버튼으로 정돈했다.
- 각 버튼에 같은 크기의 아이콘을 추가했다. 카카오맵 URL이 없으면 미연결 버튼을 표시하지 않는다.
- 사이즈북 사진과 문구의 관리자 편집은 사용자가 이전에 요청한 항목이다. 전용 메뉴는 아직 구현 전이며 관리자-후속수정.md의 목록을 유지한다.
- 다음 관리자 작업에서 상품별(꽃다발/꽃바구니), 스타일/사이즈 범위를 지켜 사진 교체, 페이지별 문구 수정, 페이지 순서·노출, 저장 전 미리보기를 연결한다.
