대전꽃백화점 · 환불정책 / 날짜·전화번호 통합 수정본

적용
1. ZIP 안 daejeon-flower-final 폴더의 내용만 기존 저장소의 같은 폴더에 덮어씁니다.
2. GitHub Desktop에서 cloudflare-latest 브랜치의 변경 목록을 확인하고 Commit → Push origin을 누릅니다.
3. Cloudflare 배포 성공 뒤 https://대전꽃백화점.com/refund 를 열어 표와 문의 링크를 확인합니다.
4. 홈페이지 하단 및 주문 화면에서 환불 안내 링크가 열리는지 확인합니다. PG 제출에는 배포 후 위 주소를 사용합니다.

수령 4일 전 또는 이전 / 3일 전 / 2일 전 / 1일 전 / 당일:
상품 실결제액 기준으로 0 / 5 / 10 / 50 / 100% 차감 안내를 표시합니다.
별도 안내·동의를 거친 적용 대상 맞춤 생화 예약에 한하며 법정 청약철회권을 우선합니다.
홈페이지의 일반 약관 동의만으로 맞춤 주문의 별도 동의를 대신할 수 없습니다.
자동 차감이나 환불 실행, 별도 동의 수집 절차는 이번 수정에 포함되지 않습니다.

이전 전화번호·달력 수정과 기념일 날짜 기준 수정도 포함했습니다.
Cloudflare 환경 변수를 덮어쓰지 않도록 wrangler.jsonc는 제외했습니다.
