카카오 로그인 Cloudflare Workers 호환 수정

카카오 로그인 토큰 발급 및 API 요청의 redirect:'error'를 redirect:'manual'로 수정했습니다.
Cloudflare Workers는 error 모드를 지원하지 않아 실제 요청 전 TypeError가 발생할 수 있습니다.
manual 모드에서 3xx 응답은 기존 r.ok 검사로 실패 처리하며 외부 주소로 인증 정보를 전달하지 않습니다.

기존 저장소 daejeon-flower-final에 덮어쓰기 후 Commit / Push합니다.
DB 준비, 카카오 키 재입력, Cloudflare 변수 수정은 필요 없습니다.
기존 운영자 로그인 상태에서 /register에 새로 접속해 '카카오로 시작하기'부터 다시 시작합니다.
이전 OAuth 콜백 주소를 새로고침하거나 뒤로 가서 재사용하지 않습니다.
실제 OAuth 완료 여부는 배포 이후 확인해야 합니다.
카카오싱크 간편가입 미연동, 웹훅 보류, 운영자 테스트 로그인 설정은 유지합니다.
