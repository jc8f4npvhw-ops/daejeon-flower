# 배송비 운영전략 검토 · 2026-10-18

현재 사용자 제공 실제 퀵비: 보통 12,000~15,000원.

2026-10-19 업데이트: 사용자 승인으로 기본 배송비 5,000원 + 지역별 추가금 정책을 반영했다. 최신 동작은 배송비-기본요금-지역추가금.md 참조. 아래 내용은 이전 검토 기록이며 배송포함 패키지·시간대 할인은 도입하지 않았다.

## 우선 제안
1. ‘배송까지 포함한 선물 총예산’을 처음부터 선택하는 배송용 패키지. 예: 10만원/15만원 총액 안에서 식물·화분·리본·지역 배송 구성. 기존 동일 상품의 배송비를 숨기거나 상품을 몰래 바꾸는 방식이 아님. 해당 예산으로 가능한 구성을 별도 사진/정보로 명시해야 함.
2. 같은 상품의 픽업가와 배송 포함 총액을 초기에 함께 안내. 주소에 따라 달라지는 비용은 먼저 산정하고 확정 총액을 결제 전 표시.
3. 배송 지원은 원가/마진이 확인된 일부 상품과 지역에 한정해 한도를 정함. 전 상품 일률 무료배송은 제안하지 않음. 배송원가와 지원액은 매장 수익에서 실제 차감됨.
4. 예약/시간대 배송은 퀵 업체가 실제 운임을 할인해 주는 조건이 확보된 뒤 검토. 초기 주문량이 적으므로 합배송으로 운임이 줄어든다고 가정하지 않음. 기존 약 ±30분 배송 안내는 유지.

## 판단에 필요한 수치
- 대표 10만원대 관엽화분의 식물+화분+포장 등 변동 원가.
- 가오동 근거리/중거리/원거리의 실제 퀵 견적과 큰 화분 추가 운임.
- 카드결제 수수료 등 기타 주문 변동비, 매장이 확보하려는 주문당 이익.
이 값으로 배송 지원 한도/배송포함 패키지 구성을 산정해야 함. 미확인 전 특정 수익률·전환율 개선 보장 금지.
