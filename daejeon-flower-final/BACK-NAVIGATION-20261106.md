# 베스트셀러 뒤로가기 수정

## 원인
베스트셀러는 크기와 스타일을 미리 선택합니다. 기존 화면 상단 뒤로가기는 마지막 data-step-back 버튼을 호출하여 스타일/크기 선택을 하나씩 해제했습니다. 앱의 주요 화면 전환도 브라우저 방문 기록과 연결되지 않았습니다.

## 변경
- 베스트셀러 진입 여부를 자동 스크롤 플래그와 별도로 유지합니다. 자동 스크롤 후에도 진입 출처를 잊지 않습니다.
- 베스트셀러에서 화면 상단 뒤로가기 한 번으로 이전 메인 화면과 스크롤 위치를 복원합니다.
- 주요 화면 이동을 브라우저 방문 기록에 연결합니다. 뒤로가기/앞으로가기에서 상품 선택을 복원합니다.
- 일반 메뉴의 화면 상단 뒤로가기는 기존의 단계별 선택 해제를 유지합니다. 숨겨진 하위 뒤로가기 버튼은 호출하지 않습니다.
- 방문 기록에는 상품 선택만 포함하며 주문 입력·연락처 등 개인정보는 넣지 않습니다. 주문 입력 중 브라우저 이동으로 나간 뒤에는 폼을 복원하지 않습니다.

## 적용
기존 cloudflare-latest 저장소의 daejeon-flower-final에 동일 폴더 내용물을 덮어쓰고 Commit/Push합니다. 추가 DB 작업이나 환경변수 변경은 필요하지 않습니다. ZIP 자체는 저장소에 넣지 않습니다. 기존 사진 경량화·베스트셀러·카카오 버튼·배송 알림을 포함합니다.

## 검증
TypeScript 타입 검사·Cloudflare/Vinext 빌드 통과. 전체 자동 테스트 67개 통과. 꽃/식물 베스트셀러의 1회 복귀, 홈 스크롤 복원, 브라우저 뒤로/앞으로 및 상품 선택 복원, 일반 메뉴 단계별 복귀를 JSDOM에서 확인했습니다. 실제 기기 확인은 배포 후 필요합니다.
