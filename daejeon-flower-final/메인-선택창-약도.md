# 메인 선택 UI · 오시는 길 · 2026-10-18

‘꽃 이름 대신, 전하고 싶은 마음부터’의 기본 select 3개를 일러스트가 있는 접이식 카드로 변경.
순간 10개, 예산 4개, 픽업/배송 기존 값과 필터 유지. 항목 선택 시 목록이 접히며 고른 내용 표시.
상품 사진을 예산 선택란에 다시 넣지 않음.

- 도로명: 은어송로51번길 38-4.
