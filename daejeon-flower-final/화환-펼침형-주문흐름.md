# 화환 주문 흐름과 축하 소개 수정 · 2026-10-19

- 축하화환 상세페이지의 협동조합 위탁 제작 소개 문구 2곳을 삭제했다.
- 대체 문구: ‘기쁜 순간을 더욱 환하게 채웁니다.’, ‘축하의 마음을 담아 — 소중한 시작에 어울리는 풍성한 꽃 인사.’
- 새 꽃 사용 안내는 유지한다. 직접 제작 문구는 추가하지 않는다.
- 근조화환 소개 문구는 이번 축하화환 문구 수정의 대상이 아니다.

## 근조·축하 공통 UX

- 화환 상품을 누르면 장소 입력란을 즉시 아래에 표시하고 부드럽게 아래로 스크롤한다.
- 상품 선택 뒤 ‘이 화환으로 다음 단계’ 확인 버튼은 제거했다.
- 앞선 선택과 입력 화면을 요약 카드로 접지 않고 그대로 표시한다.
- 장소·주문자·리본 정보를 확인하면 다음 입력 화면을 바로 추가한다.
- 스크롤 전에 다음 화면을 숨기거나 아래에서 위로 떠오르게 하는 StepReveal 애니메이션을 화환 단계와 결제 영역에서 제거했다.
- ‘이전 내용 보기’는 이전 입력란으로 스크롤하며 입력을 보존한다.
- 앞 단계의 정보를 바꾸면 뒤의 확인과 결제 영역을 닫아 변경 내용을 다시 확인하도록 한다. 기존 입력값은 보존한다.
- 고정 헤더에 입력 제목이 가려지지 않도록 스크롤 여백을 맞췄다.
- 꽃·식물 등 다른 상품의 단계 전환은 변경하지 않았다.
- 결제 조건과 서버 검증, 부고장/청첩장 구분, 개인정보 동의 조건은 유지한다.
