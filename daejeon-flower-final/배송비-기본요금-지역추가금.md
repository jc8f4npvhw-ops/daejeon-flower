# 배송비 정책 반영 · 2026-10-19

- 꽃·식물 등 기존 배송비 확인 주문의 기본 배송비는 5,000원.
- 배송비 = 기본 배송비 + 지역별 추가금. 지역 추가금은 아직 제공받지 않아 빈 목록으로 시작한다.
- 지역을 등록하지 않았거나 금액을 비워둔 경우 확인 전이며 0원으로 취급하지 않는다.
- 추가금이 없는 지역은 관리자가 명시적으로 0원을 입력한다.
- 관리자 운영 설정에서 시·구·동 이름과 추가금을 추가·수정·삭제할 수 있다.
- 고객이 선택한 지역은 예상 요금 안내용이다. 자유 입력 주소와 일치하는지 관리자가 확인한 후 배송비를 확정한다. 주소 검증 없이 지역 선택만으로 자동 결제하지 않는다.
- 고객 화면에는 기본 배송비와 추가금을 나누어 보여준다. 최종 총액은 배송비 확정 후 결제 화면에서 확인한다.
- 픽업은 배송비 0원. 기존 화환의 별도 배송비 설정은 유지한다.

## 서버와 데이터

기존 content_blocks의 STOREFRONT_V1 설정 JSON 안에 deliveryPricing={baseFee:5000,zones:[]}를 추가한다.
DB 새로 생성·스키마 교체·원격 migration을 실행하지 않았다.
기존 저장본에 새 설정이 없으면 기본 정책을 보완하며 상품·사진·관리자 변경값을 유지한다.
배송 요청 접수 시 서버가 기본료·선택 지역·예상 추가금·설정 revision을 delivery_quotes.payload_json에 기록한다.
클라이언트가 보내는 배송비나 정책 복사본은 사용하지 않는다.
관리자는 전체 요금 대신 추가금을 입력한다. 서버가 요청 당시 기본료와 합산하고 음수·소수·상한 초과를 거절한다.
기본 배송비보다 낮은 확정 요금은 거절한다. 기존 정책으로 접수된 요청은 보관된 정책을 기준으로 유지한다.
확정 배송비와 기본료·추가금은 결제 및 주문 옵션 기록에 남긴다.
미정 상태로 주문/결제를 완료하지 않으며 실제 D1·결제 연결은 기존 오픈 준비 상태를 유지한다.

보내주는 금액이 추가금인지 전체 배송비인지 확인하여 반영한다.
