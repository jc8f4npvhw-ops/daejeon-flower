# 고객 화면 확정 후 관리자 수정 시 반영할 항목

- 2026-10-19: 운영 설정에 기본 배송비 5,000원과 지역별 추가금 편집을 추가했다. 동별 추가금은 사용자 제공 대기 중이며 미정 지역을 0원으로 처리하지 않는다. 배송비 확인 요청에서는 실제 주소를 확인하고 추가금만 입력하여 확정한다.

- 꽃다발·꽃바구니 가이드북을 상품별로 관리하는 편집 메뉴 추가.
- 페이지별 제목, 사이즈 설명, 안내 문구 수정.
- 해당 상품·스타일·사이즈 사진 안에서 사진 선택 및 교체, R2 업로드 지원.
- 페이지 순서와 노출 여부 수정, 저장 전 고객 화면 미리보기.
- 현재는 상품 사진 변경이 사이즈북에 연동되지만, 가이드북 전용 문구·사진 편집 메뉴는 아직 구현하지 않음.
- 관리자 페이지 수정 작업을 재개할 때 사용자에게 이 항목을 먼저 안내할 것.

- 화환 제작 원칙 상세페이지의 사진·문구 편집. 공개용 사진은 개인정보 모자이크 처리본만 사용. 현재 화환 소개와 구성 선택은 공개하며, 실제 주문·결제 개방은 기존 상태 설정으로 관리.

- 화환은 협동조합 위탁 제작. 직접 제작 문구 금지. 새 꽃 사용 원칙으로 상세페이지 구성. 고객 단계별 화환 상담 입력 UI를 기준으로 관리자 주문 항목 연결. 현재 상담 내용은 접수·전송·DB 저장되지 않고 고객이 복사 후 채널로 전달하는 흐름.

- 화환 진입은 근조/축하 분리. 상세페이지는 근조 전용. 부고장 링크/캡처 현재는 상담 보조 UI(브라우저 메모리 미리보기)이며 자동 추출·DB 저장·캡처 전송은 미연동. 운영 연결 시 개인정보 접근·보관 정책과 함께 구현.

- 축하화환 상세페이지 및 청첩장 기반 5단계 UI 추가. 祝結婚(축결혼)/祝華婚(축화혼) 선택. 예식장·예식홀·신랑신부·예식날짜시간 관리 항목 연결 필요. 축하 사진 2장은 제공 원본의 배경 편집본이며 상품별 정확한 사진 매칭은 별도로 관리자에서 지정.

- 근조3단/4단/영정바구니 개별사진 및 축하3단 편집사진을 상품별 사진목록에 연결. 화환 종류 선택 커버는 근조 검정/축하 연분홍 배경. 오브제 상품에 축하3단 사진을 공용으로 사용하지 않고 사진 준비 중으로 표시.

- 고객 회원 마이페이지 UI를 기준으로 고객목록·동의이력·주문 귀속·D-3 대상 목록 구현. 상세 연결 계획은 회원-마이페이지-설계.md. 실제 쿠폰은 카카오 채널 관리자에서 발급·발송.

## 클래스 문의 미리보기 · 2026-10-18
- 긴 iframe 안의 native dialog 대신 부모 화면에 고정된 미리보기 사용.
- 내용이 길면 창 본문만 스크롤, 닫으면 입력/스크롤 위치 유지.
- 미리보기 하단: 내용 복사하고 카카오톡 열기. 자동 발송은 하지 않으며 고객이 붙여넣어 전송.
- 복사 실패/팝업 차단 시 직접 복사와 상담창 링크 제공.
- 카카오톡 주소 미설정이면 연결 준비 중 표시. 운영 설정의 카카오톡 채널 URL 연결 필요.


## 카카오톡 링크 수신 시 반드시 다시 안내 · 2026-10-18
사용자가 카카오톡 채널 링크를 보내면 아래 후속 작업을 먼저 리마인드한다. 지금은 연동/자동 발송/쿠폰 발급을 구현하지 않고 보류한다.
- 관리자 배송사진 업로드 → 배송완료 처리 → 주문자에게 카카오 배송완료 알림.
- 알림의 ‘배송사진 확인하기’ → 고객 전용 배송사진 → 홈페이지 후기 작성 → 다음 주문용 1,000원 쿠폰 자동 발급.
- 쿠폰은 홈페이지 전용. 배송완료 주문당 1회, 다음 결제에서 1회 사용. 유효기간/최소구매금액/비회원 수령 방식은 연결 작업 시 확정.
- 기념일 D-3 카카오 알림 및 카카오 채널 관리자 발행 쿠폰 계획과 구분한다. 위 리뷰 쿠폰은 홈페이지 자체 발급 계획이다.
- 카카오 발송 서비스·템플릿 승인·채널 연결 필요. 주문별 배송사진은 고정 이미지형 알림톡에 매번 교체하지 않고 전용 확인 링크 방식 검토.
- 배송 원본은 비공개, 공개용 제작·배송사진은 별도 선택/개인정보 가림 확인. 매장 사진과 고객후기는 출처를 구분한 모아보기.

## 관엽화분 안내 · 2026-10-18
식물 > 관엽화분 > 선택한 사이즈 제작 이미지 바로 아래 작은 문구:
‘화분은 매장 상황에 따라 변경될 수 있습니다.’
관엽화분에만 적용. 다른 상품의 안내는 변경하지 않음.


## 배송 시간 여유 안내 · 2026-10-18
- 배송 선택 카드에 도착시간 약 30분 전후 안내.
- 꽃/식물 배송 일정 선택부와 배송 주문 결제 직전: ‘배송은 요청하신 시간보다 약 30분 전후로 도착할 수 있어요. 교통·현장 상황을 고려해 여유 있게 시간을 선택해주세요.’
- 기존 작은 ±30분 문장을 아이콘이 있는 안내 박스로 교체. 픽업에는 배송 안내를 표시하지 않음.
- 근조는 고객이 배송시각을 정하는 구조가 아니므로 해당 결제에도 일반 배송 여유 원칙만 안내하며, 임의 배송시각을 생성하지 않음.

## 계절 동양난과 단계 모션 · 2026-10-18
- 계절 동양난(여름 황룡관/겨울 산천조)의 사진, 소개, 실제 입고 안내 편집 연결.
- 화분별 SKU·가격은 기존 동양난 관리 사용. 월별 출고 경계는 임의 설정하지 않음.
- 주문 customization의 계절 맞춤 안내 표시를 관리자 주문 상세 개편 때 반영.
- 공통 새 단계 등장 효과는 step-motion.tsx. 관리자 문구/가격 변경으로 모션을 다시 작성할 필요 없음.


## 식물 픽업·배송과 파일 전달 선호 · 2026-10-18
- 관엽화분/동양난 공통 PlantOrder에서 명시적인 픽업/배송 선택. 기존 ‘주소에 픽업 입력’ 판별 제거.
- 픽업은 매장/운영시간 안내, 배송 주소/수령인 입력 및 배송 지연 안내 숨김.
- 배송은 주소/수령인 필수. 전환해도 입력은 보존하되 픽업 결제 payload에 배송 개인정보를 보내지 않음.
- 상품 관리자 pickup/delivery 활성 설정 반영.
- 사용자 요청: 수정 코드 ZIP/HTML은 요청할 때만 전달. 수정본 보관은 계속하되 일상 수정 보고에 코드 다운로드 링크를 붙이지 않음.
- 배송비 전략은 논의 단계. ‘배송 포함 선물 예산’ 총액 제시 및 일부 상품 배송비 지원 검토. 구간/가격/무료배송/지원액 등 실제 정책은 확정 전 고객 UI·DB에 적용하지 않음.
