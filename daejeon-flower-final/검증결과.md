  - 관리자 문구/가격/사진 순서 저장 → 고객 화면 반영 → 재시작 후 유지, 잘못된 URL 저장 거부.
  - 웨딩·화환 준비 중 차단. 트렁크 사진 2장과 상담 경로, 직접 결제 제거.
  - 기존 D1 FINAL SQL에 추가 migration 적용. 기존 주문 테이블 유지. 관리자 로그인·CSRF·낙관적 저장 충돌·가격 재계산·픽업 제한·중복 요청·결제 금액 위변조 거부·주문 상태 버전·환불 확인·사진 R2 저장/정규 사진 연결 검증.
  - 잘못된 관리자 로그인 반복 차단.
  - 배송비 미확정 요청은 주문 결제로 생성하지 않음. 관리자 배송비 확정 → 고객 링크 → 배송비가 포함된 서버 결제 금액 검증.
- `npm run build:vinext`: RSC/SSR/client 프로덕션 빌드 통과.
- `wrangler deploy --dry-run --config dist/server/wrangler.json`: 업로드 검사 통과. `DB`와 `MEDIA`가 지정된 기존 리소스로 표시됨. 실제 배포는 하지 않음.

## 검증의 범위

D1 API는 동일한 원본 SQL을 사용하는 로컬 SQLite 어댑터로, R2와 PG는 테스트 대역으로 검증했습니다. PG에 실제 승인/취소 요청을 보내지 않았습니다. 실제 Cloudflare 계정의 D1/R2 데이터·권한을 조회하거나 변경하지 않았습니다. Browser 제어 환경이 제공되지 않아 실기기 화면의 픽셀 단위 검수는 하지 않았습니다.

## 오픈 전 실제 환경에서 확인할 항목

README 순서대로 기존 리소스에 migration·사진 업로드·배포·세션키·관리자 계정 등록을 진행합니다. 개인정보/약관/취소 정책과 판매할 상품의 미확정 가격을 관리자에서 입력합니다. 사용할 PG가 확정되면 테스트 키로 승인·실패·취소·배송비 견적 링크·중복 결제 방지를 확인합니다. 모바일 및 데스크탑에서 사진과 입력·상담 링크를 확인한 뒤 Custom Domain을 연결합니다. 과거 가비아 IP를 운영 주소로 사용하지 않습니다.
