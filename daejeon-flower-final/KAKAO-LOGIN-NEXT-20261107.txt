웹훅 서버 코드, 대기열, 0012 migration, 자동 개인정보 정리 코드는 포함하지 않습니다.
홈페이지의 톡캘린더/친구 기능 연결정보 지우기 버튼도 제거했습니다. 일반 로그아웃은 유지합니다.
KAKAO_ADMIN_KEY 등록과 웹훅 주소 등록은 하지 않습니다.
이번 수정본만을 위한 DB 준비 재실행은 필요 없습니다. 앞서 0011 포함 READY가 확인되었습니다.

기존 daejeon-flower-final 폴더에 덮어쓰기합니다.
운영자 테스트 로그인만 켜집니다(KAKAO_LOGIN_ENABLED=true, KAKAO_LOGIN_TEST_ONLY=true).
등록한 REST API 키/클라이언트 시크릿/PUBLIC_ORIGIN은 유지합니다. configure-kakao.cmd는 재실행하지 않습니다.
결제/자동발송/캘린더/친구 API 활성화 설정은 그대로입니다.
웹훅 보류로 카카오에서 연결을 해제한 사실이 홈페이지에 자동 반영되지 않습니다.

운영자 테스트 및 실제 가입화면 확보 후 동의항목 심사와 간편가입 절차는 별도 진행합니다.
