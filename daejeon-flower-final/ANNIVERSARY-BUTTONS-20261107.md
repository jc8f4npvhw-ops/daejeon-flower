# 기념일 버튼 선택 UX (일괄 배포 대기)

- 가족 / 연인 / 배우자 / 소중한 사람을 먼저 선택합니다.
- 그 아래 생일 / 결혼기념일 / 사귄 날 / 기타가 나타납니다.
- 선택한 종류에 필요한 날짜와 선택형 메모(300자)만 나타납니다. 기타는 기념일 이름도 입력합니다.
- 사귄 날은 달력에서 연·월·일을 선택합니다. 시작일을 1일로 세어 함께한 일수, 100·200·300일과 다음 100일 단위 날짜, 주년 날짜를 계산합니다.
- 저장 목록은 날짜·이름만 표시하고, 해당 행을 누르면 계산 결과·메모·수정·삭제를 펼칩니다.
- 100일 단위는 날짜 계산 기능입니다. 알림·쿠폰을 여러 건 자동 생성하지 않습니다. 기존처럼 매년 등록한 사귄 날짜를 기준으로 적용합니다.
- 윤일 안내 문구는 제거했으며 날짜 계산의 평년 보정은 유지합니다.
- 결제 완료 등록과 기존 기념일 관리 화면에 같은 입력 UI를 사용합니다.

## 배포 준비
기존 마이그레이션 0007~0009 적용 후 migrations/0010_anniversary_details.sql을 한 번 적용해야 합니다. 기존 기념일 데이터는 유지됩니다. 운영 배포와 실제 메시지·쿠폰 발급은 실행하지 않았습니다. 기존 쿠폰·알림 스위치는 변경하지 않습니다.

## 검증
자동 테스트 90개, 타입 검사, 빌드 통과. 독립 HTML에서 단계별 노출·사귄 날짜 선택·저장·목록 펼침/접힘·고객/관리자 전환을 확인했습니다. 날짜 계산, 서버 메모 저장·수정과 잘못된 날짜 거부도 테스트했습니다. 실제 기기 달력과 화면 배치는 확인이 필요합니다.
