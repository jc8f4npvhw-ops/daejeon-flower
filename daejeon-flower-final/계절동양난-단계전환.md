# 계절 동양난·단계 전환 · 2026-10-18

## 동양난
- 여름 황룡관/겨울 산천조 사진을 함께 안내하는 ‘계절 동양난’ 한 상품.
- 계절 동양난 선택 → 일반분/투각분/백자분 선택 → 주문 정보.
- 품종별 재고를 달력 월수로 추측하거나 품절 품종을 각각 주문할 수 있게 하지 않음.
- 정확한 품종은 수령일/실제 입고 확인 후 안내. 특정 품종 필수 고객은 주문 전 문의.
- 기존 SKU 동양난/화분, 가격/관리자 활성 상태 유지. 계절 맞춤 안내는 customization_json에 저장.
- 관리자 후속작업: 계절 동양난 소개·사진·입고 안내 편집 연결.

## 공통 단계 모션
- src/frontend/step-motion.tsx: 기존 단계 DOM과 입력 상태 유지. 새 단계는 화면에 들어올 때만 opacity 0 → 1, 아래 26px → 원위치, 약 0.5초.
- 꽃 상품/스타일/주문, 식물 종류/사이즈/사진/카드·리본, 동양난 화분/주문, 서양난 옵션/주문, 프로포즈 선택, 근조/축하 5단계, 결제 진입, 달력→시간목록, 선물 선택 펼침/결과, 카테고리 화면에 적용.
- 기존 부드러운 스크롤과 함께 동작. 동일 단계를 다시 선택하면 모션만 재생하며 입력값은 초기화하지 않음.
- display:none인 보존된 다른 경로를 대상으로 스크롤하지 않음.
- prefers-reduced-motion: reduce에서는 스크롤/등장 효과 최소화. IntersectionObserver 미지원 환경에서는 내용을 즉시 표시.
- 모션 종료 transform:none으로 고정 팝업의 기준 위치에 영향을 남기지 않음.
- 자동화 테스트로 상태/뷰포트 대기/접근성 설정/경로 이동 확인. 실제 기기 픽셀 단위 모션 감상은 별도 검토 필요.
