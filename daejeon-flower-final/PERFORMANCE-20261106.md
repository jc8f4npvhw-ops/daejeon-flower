# 2026-11-06 경량화·카카오 버튼·베스트셀러 바로 주문
이번 ZIP은 지난 reviewed-source 수정본 전체를 포함한 후속 버전입니다.

## 변경
1. 기존 원본 상품사진 148장을 보존하면서 320px/1280px WebP 파생 이미지를 만들었습니다.
   고객 이미지 컴포넌트가 화면 크기에 맞는 파일을 고릅니다. 작은 사진으로 크게 보기용 원본 전체를 받지 않습니다.
   목록 이미지는 지연 로딩, 메인 첫 사진과 확대창은 우선 로딩합니다.
   아직 최적화 파일이 없는 새 관리자 업로드 사진은 기존 원본 경로로 정상 표시합니다.
2. 식물 관리 HTML에서 사진·글꼴을 별도 파일로 옮겼습니다.
   HTML만 8,281,283바이트에서 233,817바이트로 감소했습니다(97.2%).
   사진과 글꼴이 사라진 것이 아니며, 전체 네트워크 전송량이나 로딩 시간이 97.2% 감소했다는 뜻은 아닙니다.
   목록은 320px 사진을 지연 로딩하고 선택한 상세에서 960px 사진을 받습니다.
   기존 글꼴과 9종 설명·동작은 유지했습니다.
3. 내용 해시가 들어간 최적화 이미지·글꼴만 장기 캐시합니다.
   상품 API, 주문, 결제, 관리자 정보, HTML에 장기 캐시를 적용하지 않았습니다.
   가격·재고는 서버 응답 전 예시 값을 표시하지 않습니다.
4. 초기 공개 CMS 요청을 화면 코드 다운로드와 병렬로 시작합니다. 새 주문·개인정보 저장 방식은 변경하지 않았습니다.
5. 카카오 이동 CTA를 노랑 #FEE500 / 검정 #191919 / 가운데 정렬로 통일했습니다.
   상담 시트, 채널 추가, 클래스 문의 전송 버튼에 적용했습니다.
6. 베스트셀러 클릭 시 SKU를 선택한 뒤 픽업·배송 구간으로 이동합니다.
   일반 상품 메뉴로 들어갈 때는 종류·크기 선택부터 시작합니다.

- 이미지 파생 파일 모두 디코딩 확인. 최적화 파일 누락 시 원본으로 돌아가는 처리 포함.
- 실제 브라우저 시각 검증은 미리보기 환경의 Cloudflare 네트워크 연결 오류로 완료하지 못했습니다.
- 한국 고객 기기에서의 개선된 실제 로딩 시간은 배포 후 확인해야 합니다.
