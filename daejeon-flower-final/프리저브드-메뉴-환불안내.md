# 프리저브드 메뉴와 환불 안내 · 2026-10-19

## 메인 분류

사용자 확인: 메인 상품 분류에 프리저브드를 추가한다.
꽃 → 식물 → 프리저브드 → 프로포즈 → 웨딩 → 화환 → 클래스.
기존 메뉴는 유지하고 좌우 스와이프·스크롤·화살표 버튼으로 이동한다.
감소 동작 설정도 지원한다.

## D 아이콘

기존 DFDSDF 아이콘 원본을 확인하고 브랜드 표현을 맞췄다.
기존 꽃 D, 식물 F, 프로포즈 D를 참조했다.
짙은 초록색 세리프 D, 검은 윤곽선, 아이보리 바탕, 색연필 질감.
D 안쪽에 분홍 보존 장미와 작은 흰 꽃이 든 유리돔을 배치했다.
확정 아이콘: public/media/preserved-d-category-v2.png
2026-10-19 수정: 유리돔 안의 다른 꽃을 제거하고 줄기와 잎이 있는 분홍 장미 한 송이만 남겼다. v1은 이전 시안으로 보존한다.
생성 시안이며 실제 판매 제품 사진으로 표시하지 않는다.

## 고객/관리자 연결

사용자 요청으로 현재는 준비 중 상태다. 메인 메뉴에 장미 한 송이 D 아이콘과 준비 중 표시를 노출하며, 진입하면 준비 중 안내를 보여준다. 기존 저장본도 최초 한 번 준비 중으로 전환한다. 이후 관리자가 공개로 변경한 상태는 보존한다.
소개·사진 편집 기능은 유지한다. 가격과 실제 제품 사진을 확정하기 전 주문·결제 상품을 임의로 만들지 않는다.
관리자 메뉴 공개 → 프리저브드에서 상태·제목·소개·준비 중 문구·메뉴 아이콘·대표사진·제작사진을 수정할 수 있다.
기존 content_blocks JSON과 공개 R2 이미지 경로를 사용한다. 새로운 DB·버킷이나 원격 migration은 실행하지 않는다.
공개 이미지 업로드는 기존 서버 prepareImages 경로를 사용한다.

## 환불 안내

일반 청약철회, 법정 제한 사유, 맞춤 주문의 별도 고지·동의, 하자·오배송, 반환 비용, 3영업일 환급 조건을 고객 안내에 반영했다.
기존 관리자 환불 문구가 있으면 보존한다. 최초 업데이트 이후 관리자 변경도 보존한다.
사용자가 제안한 3~2일 전 70%, 1일 전 50%, 당일 0%는 관리자 운영 설정의 취소정책 검토안으로 보관한다.
고객 페이지에는 이 비율을 확정된 일괄 환불 규정으로 표시하지 않는다.
자동 환불 공제 계산은 구현하지 않는다.
특별 사입만으로 법정 청약철회가 자동 제한되는 것은 아니다. 적용 대상·실제 손실·비율 유효성 검토와 주문별 별도 동의 절차가 필요하다.
