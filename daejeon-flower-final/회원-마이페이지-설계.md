# 회원 마이페이지 UI와 실제 연동 계획

## 확정한 정책

- 비회원 주문을 유지하고 회원 가입/로그인은 카카오를 사용한다.
- 카카오 로그인 후 이름·연락처·출생 연도/월/일 전체를 추가 입력한다.
- 결혼기념일·생일·기타 기념일 등록은 선택이며, 알림도 기념일별 선택이다. 기본값은 꺼짐이다.
- 알림 기준은 기념일 3일 전으로 고정한다. SMS는 제공하지 않는다.
- 카카오 로그인과 채널 친구 관계는 별도 상태다. 관계 조회 전에는 친구 추가 완료로 표시하지 않는다.
- 쿠폰은 매장에서 카카오 채널 관리자에서 발급·발송한다. 홈페이지 자동 발행·할인 적용을 구현한 것처럼 표시하지 않는다.

## 구현한 고객 UI

상단 마이페이지 입구, 카카오 로그인 진입, 가입 추가정보, 마이 홈, 주문 목록·필터·상세, 기념일 목록·월간 달력·등록·수정·삭제, 3일 전 알림 신청/해제, 내 정보 수정, 채널 혜택 안내, 비회원 주문조회 입력.

쇼핑 화면은 마이페이지가 열린 동안 숨겨져 입력 상태를 유지한다. 실제 카카오 로그인은 연결 준비 상태로 비활성화되어 있다. 로컬 미리보기에서만 가입·마이페이지 데모 진입을 제공한다. 데모 입력은 메모리에만 보관하며 서버나 브라우저 영구 저장소로 보내지 않는다. 화면을 나가거나 새로고침하면 사라질 수 있다.

주문 기본 화면은 빈 상태다. 예시 주문은 사용자가 별도 버튼을 눌렀을 때만 표시하고, 실제 주문과 구분한다. 실제 주문 조회·비회원 본인 확인·가입·기념일 저장·알림 발송·탈퇴는 아직 연결하지 않았다.

## 실제 연동 순서

1. 고객 UI 확인 및 회원 정책 확정.
2. 카카오 운영/테스트 앱, 서비스 도메인, Redirect URI, 앱-채널 연결과 권한 설정.
3. 기존 D1의 최신 스키마를 실제로 확인하고 필요한 변경만 migration으로 추가.
4. 같은 Cloudflare Workers 프로젝트에서 회원 인증·세션·회원 API 구현. DB/MEDIA binding을 서버에서만 사용.
5. 로그인 고객의 주문 조회 및 본인 확인한 비회원 조회 구현. 전화번호 일치만으로 과거 주문을 자동 귀속시키지 않음.
6. 채널 친구 관계 조회 및 기념일 수신 동의/철회 연결. 실제 발송 방식 확정 후 D-3 운영 목록/전송 결과 연동.
7. 가입·중복 계정·세션 만료·로그아웃·정보 수정·탈퇴·동의 철회·주문 소유권·알림 중복 방지 검증.

## 기존 SQL과 비교한 사항

제공된 SQL에는 customers(kakao_user_id/name/phone_normalized/email), anniversaries(month/day/occasion_type/relationship_label/notify_enabled), orders.customer_id가 있다. 기존 DB를 새로 만들거나 삭제하지 않는다.

추가 확인/확장 후보:

- 전체 생년월일 birth_date 및 가입 완료 상태.
- 회원 전용 서버 세션과 카카오 계정 연결 상태. 관리자 세션과 분리.
- 회원 약관·개인정보·기념일 알림 동의 버전, 동의·철회 시각. order_consents는 주문별 동의로 회원 동의를 대신하지 않음.
- 채널 관계 확인 시각과 실제 전송 이력, 중복 방지.
- 기존 anniversary_benefits의 D-7/2,000원 초기 설계는 최신 D-3·카카오 수동 쿠폰 정책과 다르므로 이번 단계에서는 사용하지 않음.

실제 DB migration은 아직 만들거나 원격 적용하지 않았다. 원격의 최신 스키마를 비교한 후 확정한다.

## 실제 연결 전에 받을 정보

- 카카오 앱 공개 정보(운영/테스트 구분, 앱 식별 정보), 등록된 도메인과 Redirect URI.
- 대전꽃백화점 실제 공개 카카오 채널 주소, 앱-채널 연결 여부.
- 연락처 본인 확인 방식과 회원 약관·보유·탈퇴 정책.
- 전체 생년월일 필수 수집 목적·필요성 확인 및 회원 개인정보 안내 확정. 현재 미리보기 안내를 실운영 약관으로 사용하지 않음.
- 기존 원격 D1 스키마 확인 수단.

Client Secret, 관리자 비밀번호 등의 비밀값은 채팅이나 클라이언트 코드에 넣지 않고 Cloudflare secret으로 설정한다.

## 기념일 날짜 처리

서울 기준 날짜로 다음 기념일과 D-3 기준일을 표시한다. 양력 매년 반복만 제공한다. 2월 29일은 평년에 2월 28일로 표시한다. 가입자의 생년월일을 별도 신청 없이 기념일 알림에 자동 등록하지 않는다. 쿠폰·행사 등 광고성 혜택과 기념일 알림의 동의 범위를 동일하게 간주하지 않는다.
