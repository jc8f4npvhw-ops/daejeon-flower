# 대전꽃백화점 모바일 홈페이지 v1

지금까지 대화에서 확정한 내용을 반영한 Next.js 1차 통합 프로토타입입니다.

## 실행
1. 압축 해제
2. VS Code에서 `daejeon-flower-site` 폴더 열기
3. 터미널에서 `npm install`
4. `npm run dev`
5. 브라우저에서 `http://localhost:3000`

## 현재 반영
- 첫 화면 7개 카테고리
- FLOWER: 꽃다발 / 꽃바구니 / 화병꽃이 / 센터피스
- FLOWER 스타일·사이즈 선택 및 사이즈별 슬라이드 이미지 자리
- FLOWER 픽업 / 배송 / 주문정보 / 개인정보 동의 / 결제 UI
- PLANT: 개업축하 / 동양난 / 서양난
- 개업축하 사이즈별 슬라이드 이미지 자리
- 동양난 황룡관·산천조 작은 세로 배치
- 동양난 일반분 70,000 / 투각분 100,000 BEST / 백자분 180,000
- 서양난 5/6/8/10/15만원 + 보자기 15,000 + 픽업/배송 + 결제
- 카드 메시지 / 리본문구 단일 선택
- JUST ROSE 색상 꽃말 + 20/30 BEST/50/100송이 + 픽업/배송 + 결제
- 트렁크 메인 슬라이드 + BASIC/SIGNATURE BEST/PREMIUM + 결제
- 호텔 메인 슬라이드 + 4패키지 + 추가상품 + 진행과정 + 예약정보 + 결제
- 근조 3단 BEST / 축하 3단 BEST
- 개인정보처리방침 모달 + 사업자 푸터
- 주요 선택 후 부드러운 자동 스크롤
