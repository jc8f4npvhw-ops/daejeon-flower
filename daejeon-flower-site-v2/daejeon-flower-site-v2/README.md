# 대전꽃백화점 홈페이지 v2

UrbanStems의 쇼핑 직관성과 Instagram 프로필/하이라이트/피드의 익숙한 탐색 문법을 결합한 모바일 우선 프로토타입입니다.

## 실행
1. 압축 해제
2. VS Code에서 `daejeon-flower-site-v2` 폴더 열기
3. `npm install`
4. `npm run dev`
5. `http://localhost:3000`

## Vercel
GitHub 저장소 안에 이 폴더 자체를 넣으면 Vercel Root Directory를 `daejeon-flower-site-v2`로 지정하세요.
폴더 안의 파일을 저장소 최상단에 올리면 Root Directory는 비워두면 됩니다.

## v2 핵심 변경
- 첫 진입 랜딩 화면 + 이미지 무브먼트 느낌 + 브랜드 타이포그래피
- 랜딩에서 `바로 주문하기 / 상담하기`
- 프로필형 브랜드 소개
- Instagram 하이라이트처럼 보이는 원형 퀵메뉴
- 상품으로 찾기와 Occasion으로 찾기를 분리
- 생일 / 기념일 / 졸업 / 인사이동 / 개업 / 감사 큐레이션
- 3열 브랜드 피드: 사진을 누르면 주문/상담 페이지로 이동
- 검은 사각 버튼 반복을 줄이고 사진·여백·얇은 선택 표시 중심으로 변경
- 아이폰 Safari에서 버튼/링크가 임의로 파란색이 되지 않도록 기본 색상 고정
- FLOWER S 사이즈는 픽업 전용, 배송은 M부터
- 픽업 시간 30분 단위 선택
- 꽃다발/꽃바구니/화병꽃이/개업축하 사이즈 선택 후 이미지 슬라이드
- 동양난 황룡관/산천조 소형 세로 배치
- 동양난 일반분 70,000 / 투각분 100,000 BEST / 백자분 180,000
- 서양난 예산 → 보자기 옵션 → 픽업/배송 → 결제
- JUST ROSE 픽업/배송
- 트렁크/호텔 메인 슬라이드 + 결제
- 근조 3단 BEST / 축하 3단 BEST
